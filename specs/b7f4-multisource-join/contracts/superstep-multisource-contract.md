## 2. 图规格（`GraphSpec`）—— 边表

### 2.1 边表的**键类型**（**唯一**的形态变化）

| 项 | 契约 |
|---|---|
| 键类型 | `str \| tuple[str, ...]` |

| 输入 | 规范化结果 | 依据 |

## 3. 触发判定（**组**）

### 3.1 触发源**组**（**新概念** · 零新增类型）

```text
组 = tuple[边触发源, ...]        边触发源 = ("e", 源节点名)
```

| 项 | 契约 |
|---|---|
| **组的单位** | **每条入边一个组**（不是「每个源一个组」）<br>⚠️ **补充（澄清轮 **C-Q16**）**：**同成员的多条边合成一组**（见下方「去重」· research **DR-3**）⇒ ⇒ 「每条入边一个组」是**枚举期**的口径，**去重后**才是 `groups(N)` 的内容 |
| **单源边** | 组 = `(("e", 源名"),)` —— **单元素** |
| **多源边** | 组 = 该边**全部**源的边触发源（元组） |
| **动态边** | 组 = **单元素**（`Command.goto` 恒为单源） |
| **去重** | 按**成员集合**（`frozenset`）去重（**保序**）⇒ 同成员的两条边合成一组（research **DR-3**）<br>⚠️ **与上游的对照（2026-11-13 · 实测 E-11 · 旧附注已被证伪 · 本行为面零分叉）**：上游把**顺序写进 join 通道名** ⇒ `("a","b")→c` 与 `("b","a")→c` 是**两个不同通道** ⇒ **但上游的触发汇总是 `triggered_nodes: set[str]`（按**节点**去重** · `_algo.py:476-482`）⇒ ⇒ 上游同样只触发 1 次**（实测 **E-11** ⇒ 执行序列 `['a','b','c']`）⇒ ⇒ freegraph 的「按**成员集合**去重 ⇒ 合并为一组 ⇒ 触发一次」**与上游逐字同款** ⇒ ⇒ **行为面零分叉**（**无需偏离登记**）⇒ ⇒ 该行为 MUST 以**差分场景 D-27 锁住**（防回归） |
| **顺序** | **边表的声明顺序**（静态在前 · 动态在后）⇒ 记账顺序**可复现** |

### 3.2 判定规则（**逐字**）

```
节点 N 被触发 ⟺ ∃ 组 g ∈ groups(N) : ∀ s ∈ g : version(s) > seen(N)[s]
```

* `groups(N)` = **所有指向 N 的边**各成的**组**（静态边 ∪ 动态边 · **同处一个空间** ⇒ 叠加）。
* `seen(N)` = `SchedulerState` 里 N 的**已消费版本**记录（**节点名 → {触发源 → 版本}** · 结构**不变**）。
* **单源口径的退化**：单源边的组是**单元素** ⇒ 上式**逐字退化**为 B7F1 的旧判定式
  「∃ 触发源 s ∈ sources(N) : version(s) > seen(N)[s]」⇒ **既有行为零变化**。
* **多源口径**：组内**全**（AND / 屏障）；**组间任一**（上游同款 · 实测 **E-3 / E-4**）。
* ⚠️ **上游的 join 通道只在 `end != END` 时创建**（`langgraph/graph/state.py:1560` 的
  `elif end != END:`）⇒ ⇒ 上游 `add_edge(["a","b"], END)` = **静默 no-op**（实测 **E-9**）
  ⇒ ⇒ freegraph 对 `__end__` 目标**显式失败**（**V-16** · 语义点 **P-15** · 偏离登记 **X-04**）
  ⇒ ⇒ 该口径**比上游更严**（失败面）⇒ **行为面**（屏障语义）仍**逐字照抄**。
* **无「有值」合取项**：边触发源**没有**「值」概念（沿用 B7F1 契约 §3.2）。

### 3.3 消费（**记账**）

| 项 | 契约 |
|---|---|
| **时点** | N 被**准备执行**时（阶段 ②）⇒ 与 B7F1 既有时点**相同** |
| **范围** | **只消费「已满足的组」的源** ⇒ 每个被消费的源**各记一条** `seen[(kind, ident)] = version(ident)` |
| **未满足的组** | **不记** ⇒ 屏障后来齐了**仍能再次触发**（上游同款 · 实测 **E-5**） |
| **单源口径的等价性** | 未满足 ⇒ `version ≤ seen` ⇒ 版本只增不减 ⇒ `version == seen` ⇒ 旧口径的同值记账 ⇒ **行为逐字不变** |
