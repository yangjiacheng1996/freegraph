## Summary

**交付什么**：让 L2 调度内核**能表达并正确执行**「**多源汇合边**」—— 一条边的**源是多个节点**、
目标是**一个**节点 ⇒ 目标 MUST 等到「**该边的所有**源都跑过」才被触发（**AND / 屏障**语义）
⇒ ⚠️ **组内全 · 组间任一**：一个节点同时有「单源入边」与「多源入边」时，**任一**入边满足即触发
（**上游同款** · 实测 **E-3** · 澄清轮 **C-Q1** / 裁定 3 ⇒ 见 spec **FR-003**）。

**技术路线**（零第三方依赖 · 零出站 · 零环境变量 · **零新增导出符号**）：

| 关注点 | 落法 |
|---|---|
| **表达** | `GraphSpec.edges` 的**键类型**由 `str` 放宽为 **`str \| tuple[str, ...]`** ⇒ 键为元组 = 「这些源**共同**汇合到目标」⇒ **单源边的写法逐字不变**（既有调用方零改动） |
| **载体** | **不新增通道类型** ⇒ 屏障语义**完全**由**触发层**实现（**触发源组** + `seen`）⇒ **不破** B5F1 的通道冻结面 ⇒ `runtime.__all__` **仍为 20** |
| **判定式** | **∃** 组 g：**∀** s ∈ g：`version(s) > seen(N)[s]`（**组内全 · 组间任一**）⇒ **上游同款**（实测 **E-3 / E-4**）⇒ **单源口径逐字退化为** B7F1 的旧判定式 |
| **记账** | 只记「**已满足的组**」的源（**逐源各一条**）⇒ 未满足的组**不记账** ⇒ 屏障后来齐了**仍能再触发**（**上游同款** · 实测 **E-5**）⇒ **单源口径行为逐字不变**（未满足 ⇒ 同值记账） |
| **失败信号** | 缺源 ⇒ `ValueError`（**V-2** 同族 · **点名**）· 空元组 / 含 `__start__` / 目标数 ≠ 1 / **目标为 `__end__`** ⇒ `ValueError`（**V-16**）· 边键**类型**非法 ⇒ `TypeError`（**上游同族** · **FR-021**）⇒ **零新增错误类型** |
| **并发无关** | 屏障在**串行档与并发档**产出**同一**可观察结果（**上游同款** · 差分 **D-20**）⇒ 前置依赖 **B12F1** 是**顺序**要求，不是**逻辑**要求 |
| **不越界** | **不**做 `defer=True` 专用屏障 · **不**做跨 checkpoint 持久化 · **不**做条件边路由 · **不**做构建器接线 · **不**做编译层重建屏障语义 · **不**做兼容矩阵条目（**D-1…D-7** 承接）· **不**新增可观测面（**D-7** → **B19F1**） |
| **可验证出口** | 差分探针追加 **D-16…D-28**（**SAME 11 条** = **D-16…D-24 / D-27 / D-28** · **STRICTER 2 条** = **D-25 / D-26** · **D-24** = **参数化**增量 · 兑现立项书 §4.2 **S5 ③** · **D-28** = 兑现 **C-Q10** 的「类型族」承诺 · 澄清轮 **C-Q14**）+ 多源口径单元用例（新文件）+ **一键验收脚本** + **五段式人工验证记录（含追认）** |
| **门禁偏离登记** | 门禁 **3 / 4 / 5** 的三部分在本 feature **物理不可达成**（只交付 L2 ⇒ 无图可跑）⇒ 按宪法 **v1.6.0** **如实登记**（**PR-5** · 判据一字不改 · **不**写永久红 CI）⇒ **并入**同一次追认 |

**上游对齐口径**（宪法 **v1.9.0** 原则 XI）：**内容照抄上游 + 形态取最优**（原则 **XII**）⇒
