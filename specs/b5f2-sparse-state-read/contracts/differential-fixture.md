# 差分夹具契约（Differential Fixture Contract）—— B5F2 的**唯一权威**

**Feature**: `B5F2` · **Spec**: [../spec.md](../spec.md) · **Plan**: [../plan.md](../plan.md)
**读取契约权威**: [read-contract.md](./read-contract.md) · **上游证据**: [upstream-parity.md](./upstream-parity.md)

> **本文件是「差分夹具怎么用、比什么」的**唯一权威**。
> **落位**：**测试侧**（`tests/differential/`）⇒ **MUST NOT** 进入 `src/freegraph/**`
> （spec 裁定 6 · FR-024）⇒ 内核的零依赖面**不受影响**。

---

## 1. 夹具的**形状**（**冻结**）

| 项 | 契约 |
|---|---|
| 落位 | `tests/differential/`（**测试侧** · 不进发行包 · `pyproject` 的 sdist `exclude` 已含 `/tests`） |
| 入口 | 一个**可复用的**夹具入口（`pytest` fixture 或一个纯函数）⇒ **B8F1 MUST 能直接复用**（FR-015） |
| 依赖 | `langgraph`（**缺席 ⇒ skip**）· `pytest`（既有 dev 组）· **零新增第三方** |
| 驱动 | **规格驱动器**（测试侧）：只用 **B5F1 通道层 + B5F2 读取层** ⇒ **MUST NOT** 含调度逻辑（裁定 6） |

---

## 2. 图规格（Graph Spec）的形态（**冻结**）

| 字段 | 形态 | 说明 |
|---|---|---|
| `schema` | **字段描述**：`{key: (value_type, reducer \| None)}` | **纯数据**（不携带 `TypedDict` 类） |
| `schema_typed` | **运行时动态构造**的 `TypedDict`（**一个**） | `typing.TypedDict("名称", {...})` 的**函数式**写法 ⇒ **两侧消费同一个对象**（FR-033 · 裁定 21） |
| `nodes` | `[(节点名, 节点函数)]`（**有序**） | 节点函数签名 = `f(state: dict) -> dict`（返回**部分**状态） |
| `initial_input` | `dict` | 按「**一次写入**」进通道（FR-029 · 裁定 16） |
| `conditional_edges` | **恒空**（本 feature） | **预留字段** ⇒ 非空 ⇒ **显式失败**（MUST NOT 静默忽略 · 裁定 15） |
| `model_factory` | **恒空**（本 feature） | **预留的「模型工厂」钩子** ⇒ 非空 ⇒ **显式失败**（MUST NOT 静默忽略 · MUST NOT 自行实现 fake 注入 · FR-036 · 裁定 26） |

**约束**：

- 图规格 MUST 表达**线性单链**（节点按 `nodes` 的次序串行执行 · 无分支 · 无并行）；
- 图规格 MUST **恒为纯本地节点**（无模型调用）⇒ `model_factory` 字段 MUST **恒空**
  （本 feature 恒空 ⇒ 非空即**显式失败**）⇒ fake 注入与**模型形状**的图规格归 **B25F1**
  （FR-036 · 裁定 26 · research **DR-5**）；
- MUST **NOT** 用 `exec` / 动态求值构造 schema（FR-033）；
- 节点函数 MUST 是**确定性**的（否则两侧输出可能不同 ⇒ 假差异）；
- 节点函数 MUST **NOT** 发起网络调用（零出站红线 · 裁定 13）；
- 节点返回的 key MUST **全部在** schema 里 ⇒ 否则**前置校验失败**（research **D-15** / **DR-2**）。

## 3. **三项**投影的口径（**冻结**）

### 3.1 节点入参（**C4 的载荷**）

| 项 | 口径 |
|---|---|
| 采集方式 | 在**节点函数内部**把收到的字典**复制一份**留存（副本取自**节点执行前** · FR-030 · 裁定 17） |
| 归一化 | `dict` ⇒ key 集合 + 逐 key 值（按 `==` 比，**不**比实例同一 · ⚠️ 也**不**比 **key 顺序** ⇒ 见 §5） |
| 比对 | 两侧的 key 集合**逐项相等** 且 逐 key 值**相等** |

### 3.2 输出状态

| 项 | 口径 |
|---|---|
| freegraph 侧 | 规格驱动器结束时，**有值**通道的 `key → 值` 映射（**稀疏** · 无值 key **缺席**） |
| langgraph 侧 | `invoke()` 的返回值（**已实测**：无值 key **不出现在输出里**） |
| 比对 | 两侧的 key 集合**逐项相等** 且 逐 key 值**相等** |

### 3.3 事件序列（**归一化后**再比）

| 项 | 口径 |
|---|---|
| 归一化形态 | `[(步序, 节点名, 写入)]` 三元组序列 |
| 「写入」投影 | **该节点函数返回的部分状态（原样 · 未归约）**；**无更新 ⇒ `None`**（**实测冻结** · research **D-14** · 裁定 7 · FR-034） |
| ⚠️ **MUST NOT 取「通道归约后的累计值」** | 归约型通道上二者**不同**（节点 A 写 `['a']` · 节点 B 写 `['b']` ⇒ 返回值投影 `['a']` / `['b']`，归约后 `['a']` / `['a','b']`）⇒ 取法不同 ⇒ **稳定假差异** |
| langgraph 侧来源 | `stream(stream_mode="updates")` ⇒ 逐事件取 `{节点名: 写入}`（该「写入」= **节点返回值**） |
| 比对 | 三元组序列**逐项相等**（含**步序**与**节点名**） |

> ⚠️ **「空更新」计入事件序列**（实测：节点返回 `{}` / `None` / 未知 key 一律产出 `{'<node>': None}`）
> ⇒ freegraph 侧 MUST 产出**同一形态** ⇒ 否则稳定报**假差异**。

## 4. 比对的**判定**（**冻结**）

| 结果 | 条件 |
|---|---|
| **一致** | 三项投影**全部**逐项相等 |
| **不一致** | 任一投影存在差异 ⇒ MUST 报告**具体字段**（哪个 key / 哪个步序 / 期望值 vs 实际值） |
| **跳过** | `langgraph` **缺席** ⇒ **skip**（**MUST NOT** fail · FR-019 / 裁定 11） |

⇒ 判定记录 MUST 含**比对字段名 + 逐项结果**（MUST NOT 只写「一致」· FR-017 / SC-019）。

---

## 5. **不进入**比对的范围（**冻结**）

| 场景 | 理由 |
|---|---|
| **未知 key 的写入** | 上游**静默丢弃**、freegraph **显式失败** ⇒ 两侧**不等价地失败** ⇒ 假差异（research **D-15** / **DR-2**）⇒ 该场景由 freegraph 的**单元测试独占断言**（⚠️ 权威口径是**立项书 C6**「未知 key 报错」⇒ freegraph **一致**、**上游偏离**） |
| **模型形状的图规格**（含 fake 模型注入） | 本 feature **恒为纯本地**（`model_factory` 恒空 ⇒ 非空即显式失败）⇒ 归 **B25F1**（fake 轮）与 **B8F1**（路由形状）（FR-036 · 裁定 26 · research **DR-5**） |
| **条件边 / 路由** | 属 **B8F1**；本 feature 的 `conditional_edges` 恒空 |
| **并行节点** | 属 **B12F1**（super-step 概念） |
| **非确定性节点** | 会造成假差异 ⇒ 前置校验拒绝 |
| **key 的顺序**（节点入参 / 输出状态两项投影的归一化） | 归一化只取「**key 集合** + 逐 key 值」⇒ **顺序不比对** ⇒ `read-contract.md` §4 **I-2**「结果 `dict` 的 key 顺序 == 入参映射的顺序」**不被差分证据覆盖**（该保证由**读取层自身的单元测试**守护 · `tests/runtime/test_read_semantics.py`）⇒ ⚠️ 上游的入参 key 顺序由其 `select` 决定（实测基线里为**字母序**）⇒ 若比对顺序将产生**稳定假差异** ⇒ **只登记、不比对**（裁定 33 ④ 配套 · 2026-11-10 分析轮第二轮） |

## 6. 与上游的**可核对性**（**冻结**）

- 差分夹具 MUST 在**钉住的上游版本**（`langgraph 1.2.11`）上运行 ⇒ 版本 MUST 记入判定记录；
- 上游侧的**期望值** MUST 取自 [upstream-parity.md](./upstream-parity.md) §2 的**实测基线**
  （MUST NOT 凭记忆写期望值）；
- 上游版本升级时 ⇒ MUST **重新实测**该基线（MUST NOT 沿用旧值）。
