## 2. 节点返回值（三形态 · **归一为一种内部形状**）

| 形态 | 语法 | 归一后的待写入 | 归一后的跳转目标 |
|---|---|---|---|
| **部分状态** | `dict` | 该 dict 的 items（键序 = 插入序） | （无） |
| **单条命令** | `Command` | `command.update`（若 `not None`）的 items | `command.goto`（若 `not None`） |
| **命令列表** | `list[Command \| dict]` | **按列表顺序**把各元素归入同一份 | 各条命令 `goto` 的**并集**（保序去重） |

**统一形状**（内部中间产物 · **不进公开面**）：

```text
{"writes": dict[str, tuple[Any, ...]], "gotos": tuple[str, ...]}
```

⚠️ **归一是唯一的新增概念** ⇒ 三种形态归一后**只有一种内部表示** ⇒
「未知 key 报错」「归约器语义」「批量合并」「原子性」**全部复用 B7F1 的同一条路径**。
⚠️ **`writes` MUST 是「每 key 一个**值序列**」**（**不是** `dict[str, Any]`）——
命令列表里**两条命令写同一个 key** 时，单值形态会**后者覆盖前者** ⇒ 违反「不覆盖」与「按列表顺序归约」
⇒ **2026-11-11 分析轮（发起者拍板 · Q1）** 冻结为**值序列** ⇒ 与 B7F1 的 `node_writes`
（节点 → 通道 key → **值序列**）**同构** ⇒ 合并路径**零改动**。

## 3. `goto` 的形态解析（**逐字**）

| 输入 | 解析结果 | 说明 |
|---|---|---|
| `None` | 无跳转 | 该位**未提供** |
| `str`（**先判 `isinstance(x, str)`**） | **一个**目标 | ⚠️ `str` 本身也是 `Sequence[str]` ⇒ **顺序判断会把它拆成字符序列**（L1 docstring 逐字点名） |
| `Sequence[str]`（非空） | **多个**目标（保序去重） | 每条目标各自成边 |
| `Sequence[str]`（空） | 无跳转 | 「显式给了但内容为空」= **该位不产生动作** |
| 终止标记 `"__end__"` | **无跳转**（该位不产生动作） | 与门面的 `END` **逐字相等**；⚠️ **不终止整张图**（其它触发源照常推进）⇒ **终止是「收敛」的结果** |
| `Command.PARENT`（= `"__parent__"`） | **显式失败** | `NotImplementedError` · 点名「子图属 v2 能力」 |
| 其它 `str`（不在节点表 / 空串 / `START`） | **显式失败** | `ValueError` · 点名目标 |
| 其它类型 / 序列含非 `str` | **显式失败** | `TypeError` |

⚠️ **终止标记以**字面量**判定**（L2 **MUST NOT** import 门面 · ARCH-1）⇒
门面的 `END` 值 MUST 与该字面量**逐字相等**（**可自动核对**）。

## 4. `update` 的形态解析（**逐字**）

| 输入 | 解析结果 |
|---|---|
| `None` | 无写入（该位**未提供**） |
| `dict`（**空**） | 无写入（该位**不产生动作**） |
| `dict`（非空） | 逐 key 归入待写入 |
| 其它类型 | **显式失败**（`TypeError`） |

## 5. 跳转的落点（**边触发源空间**）

| 项 | 契约 |
|---|---|
| 触发源标识 | `("e", 源节点名)` —— **边空间**（与通道空间 `("c", key)` **分离** · B7F1 裁定 3） |
| 版本 | 源节点的**执行版本**（每执行成功一次 +1）⇒ 与静态边**同款** |
| 判定式 | `version(s) > seen(N)[s]` —— **无「有值」门槛** ⇒ 目标**订阅的通道都没值也照跑** |
| 生效时机 | **下一轮**（本轮触发判定已过 ⇒ 本轮不产生新的触发） |
| 生命周期 | 由源节点的**最近一次执行**决定 ⇒ 再次执行且不给 `goto` ⇒ **旧目标被清空** |
| 与静态边 | **叠加**（静态边目标与 `goto` 目标**都**在下一轮被触发） |
| 目标的入参 | **正常稀疏读**的结果（= `read_channels(子映射)` · 子映射按**通道映射顺序**构造）⇒ **读得到**源节点本次 `update` 的内容 |

---

## 6. 写入合并（**与普通返回值同一条路径**）

| 规则 | 内容 |
|---|---|
| **一条路径** | 归一后的待写入交给**同一个**合并实现 ⇒ 未知 key / 归约器 / 覆盖型冲突 / 原子性 **全部复用** |
| **批量** | 每通道**一次** `Channel.update(values)`（B7F1 FR-005） |
| **归约型** | 按序逐个归约（列表写法 ⇒ **按列表顺序**） |
| **覆盖型多写** | **显式失败**（`InvalidChannelUpdateError` · B5F1 既有类型） |
| **未知 key** | **显式失败**（`InvalidUpdateError` · L1 · `invalid_keys` 列**全部**） |
| **归属** | 写入归到**返回它的那个节点**名下（`node_writes` 的**按节点分组**） |
| **原子性** | 本轮出错 ⇒ **全部**待写入不合并 · 通道值保持轮初 · **版本不推进** |

| # | 场景 | 信号 | 消息 MUST 点名 |

| **V-9** | 返回值形态非法（含 `None`） | `TypeError` | 返回值的类型 |

## 9. 不变量（**逐条可断言**）

| # | 不变量 | 可判定方式 |
|---|---|---|
| **I-1** | 返回值**只有三种合法形态** | 形态穷举 + 非法形态 ⇒ `TypeError` |
| **I-2** | 三形态归一后**共用同一条合并路径** | 同一 key 三种写法 ⇒ 结果**逐项相等** |
| **I-3** | `Command.update` 归**源节点** | `node_writes` 的 key 集合 |
| **I-4** | 列表写入**按列表顺序**合并 | 与「按序逐条写入」**逐元素相等** |
| **I-5** | 列表里每条 `goto` **各自成边** | 全部目标**都**被执行 |
| **I-6** | 动态边**整体替换** | 再次执行无 `goto` ⇒ 旧目标不再被触发 |
| **I-7** | 目标**下一轮**才被触发 | 同轮内目标未被执行 |
| **I-8** | 目标**无「有值」门槛** | 订阅通道无值仍被执行 |
| **I-9** | 目标入参 = **正常稀疏读** | 与 `read_channels(子映射)` **逐字相等** |
| **I-10** | 目标**读得到**本次 `update` | 目标入参含该内容 |
| **I-11** | 动态边与静态边**叠加** | 两个目标都被触发 |
| **I-12** | `END` **不跳转、不终止** | 静态边目标仍被执行 + 更新生效 |
| **I-13** | 空槽位 / 空列表 = **无操作** | 零写入 + 零跳转 + 计入执行记录 |
| **I-14** | 结果对象**四字段** | 字段数断言 |
