## Phase 3: User Story 1 - 一轮 super-step 能跑通（Priority: P1）🎯 MVP

**Goal**: 手写的**节点规格 + 边规格**直接驱动**一轮** super-step —— 被触发的节点执行一次、
状态按通道语义合并、五阶段的产物逐项可观测（**四项**口径 · FR-001 / SC-001 的收窄：
**执行记录** / **待写入** / **合并后状态** / **轮数**）。

**Independent Test**: 给定一份手写图规格（通道 + 节点 + 边）⇒ 执行一轮 ⇒ 断言「被触发的节点执行
**恰好一次**」「未被触发的节点执行 **0** 次」「合并后状态与期望逐项相等」三件事 ——
**不经由 `StateGraph` / `compile()`**。
