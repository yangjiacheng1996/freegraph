## 提示词正文

### 1. 目标

实现**稀疏状态读取**语义，并把「差分测试夹具」建立起来：同一份图规格同时跑
`langgraph` 与 `freegraph`，比对输出状态与事件序列是否一致。C4（稀疏状态）是全项目
**最易被静默破坏**的两条契约之一，本 Phase 用**独立回归测试**把它钉死。

### 2. 背景与上下文

- **C4 稀疏状态**：节点收到的入参是**普通 `dict`**，且**只包含当前有值的 channel**。
  空 channel 的 key **MUST NOT** 出现在入参中。
  - 后果（实测依据：`langgraph/pregel/_io.py:38-53`，实测 `NODE_INPUT_KEYS: ['messages']`）：
    若空 key 出现在入参里，`target.py:100` 的 `state.get('llm_calls', 0)` 会返回 `None`
    而不是 `0`，于是 `None + 1` 抛 `TypeError`——**脚本在验收点上崩掉**。
- **C8 fresh 读**（条件边读状态）是另一条最易错的契约，落在 **F8P1**；本 Phase 建立
  的**差分夹具**将在 F8P1 被复用。
- **差分测试的依赖隔离方式**（立项书 §4.2 S5 / S6）：`langgraph` 只作为
  **dev / test 依赖**，**绝不进入 `freegraph` 的 `Requires-Dist`**——因此既不破坏依赖
  红线，又能拿到最强的等价证据。
- 状态读取 MUST 收敛为**单一抽象点**（架构纪律），否则「稀疏」与「fresh」两条语义
  会在多处实现里分叉。

### 3. 用户场景

**P1 — 空 key 不出现在节点入参里**
作为用户，我的 schema 有 `messages` 与 `llm_calls` 两个 key；当 `llm_calls` 尚未被写入过，
我希望节点收到的 dict **不含** `llm_calls`，从而 `state.get('llm_calls', 0)` 返回 `0`。

- **独立验收**：断言 `"llm_calls" not in node_input` 且 `node_input.get("llm_calls", 0) == 0`。

**P2 — 节点入参是普通 dict**
作为用户，我希望节点的第一个参数是**普通 `dict`**（不是自定义映射、不是属性对象），
以便 `state.get(key, default)` 与 `state["key"]` 的语义完全符合直觉。

- **独立验收**：断言 `type(node_input) is dict`（或至少是 `dict` 的实例且非自定义子类
  的行为差异）。

**P3 — 与 LangGraph 的行为可逐项比对**
作为维护者，我希望有一套**可复用的差分夹具**：给定一份图规格，断言 freegraph 与
langgraph 的**输出状态**与**事件序列**一致，从而把「等价」从主张变成证据。

- **独立验收**：差分夹具对至少一组「有归约器 + 无归约器 + 空 key」混合的图规格，
  比对结果一致。

### 4. 功能需求

- **FR-001**：系统 MUST 提供状态读取的**单一抽象点**，实现「跳过空 channel」的读取模式
  （对应 LangGraph `read_channels(skip_empty=True)` 的语义）。
- **FR-002**：读取结果 MUST 是**普通 `dict`**，且**只含有值的 key**（C4）。
- **FR-003**：系统 MUST 提供「fresh 读」模式：返回「当前值 + 本任务本次写入」的视图，
  且**不污染**通道中的正式值（供 F8P1 的条件边使用；本 Phase 交付读取原语，
  路由语义在 F8P1）。
- **FR-004**：系统 MUST 提供 **C4 独立回归测试**，断言：节点入参不含无值 key、
  `.get(key, default)` 返回 default 而非 `None`。
- **FR-005**：系统 MUST 建立**差分测试夹具**：同一份图规格可分别在 `langgraph` 与
  `freegraph` 上执行，比对**输出状态**与**事件序列**。
- **FR-006**：`langgraph` MUST 以 **dev / test 依赖**引入（如 `[dev]` extra 或
  `requirements-dev.txt`），**MUST NOT** 出现在 `freegraph` 的 `Requires-Dist`。
- **FR-007**：差分夹具 MUST 在 `langgraph` 缺席时**优雅跳过**（标记 skip 而非失败），
  以保证基础安装环境的 CI 可运行。
- **FR-008**：系统 MUST NOT import `langchain` / `langchain-core`（内核路径上）；
  `langgraph` 的导入**只允许出现在测试代码与 dev 依赖中**。

### 5. 成功标准

- **SC-001**：C4 回归测试常驻 CI 且通过——`"llm_calls" not in node_input` 与
  `.get("llm_calls", 0) == 0` 两条断言 100% 成立。
- **SC-002**：节点入参类型为 `dict`，且 key 集合 == 「当前有值的 channel 集合」。
- **SC-003**：fresh 读模式下，写入任务的视图包含本次写入，而通道正式值不被提前固化。
- **SC-004**：差分夹具在「有归约器 + 无归约器 + 空 key」混合图规格上，
  freegraph 与 langgraph 的输出状态与事件序列**一致**。
- **SC-005**：freegraph 的发行依赖声明中**不含** `langgraph`（CI 依赖门禁持续通过）。

### 6. 验收判据（= 立项书 §5.2 F5P2 小目标，逐条可判定）

> 小目标原文：C4 独立回归测试通过：`"llm_calls" not in node_input` 且
> `.get("llm_calls", 0) == 0`；**差分测试夹具建立**：同一图规格在 `langgraph` 与
> `freegraph` 上的输出状态与事件序列一致（`langgraph` **仅作 dev/test 依赖**，
> 不入 `Requires-Dist`）

| # | 判据 | 判定方式 |
|---|---|---|
| A1 | `"llm_calls" not in node_input` | C4 独立回归测试断言 |
| A2 | `.get("llm_calls", 0) == 0` | C4 独立回归测试断言 |
| A3 | 差分夹具：输出状态一致 | 夹具在混合 schema 图规格上比对通过 |
| A4 | 差分夹具：事件序列一致 | 夹具比对通过 |
| A5 | `langgraph` 不入 `Requires-Dist` | CI 依赖门禁断言 |

### 7. 关键实体与契约

| 实体 | 语义 | 对应契约 |
|---|---|---|
| 稀疏状态读取 | 只含有值 key 的普通 dict | **C4** |
| fresh 读视图 | 「当前值 + 本任务本次写入」 | **C8**（读取原语在此，路由语义在 F8P1） |
| 差分夹具 | 同规格双实现比对 | 立项书 §4.2 S5「等价证据三层」第 ② 层 |

> **口径提醒**：C4 与 C8 是**两条必须独立回归**的契约（立项书 §5.3 末节）。
> 本 Phase 交付 C4 的回归测试；C8 的回归测试在 F8P1，但本 Phase 的 fresh 读原语是
> C8 回归测试的实现基础。

### 8. 边界（本 Phase 明确不做）

- 不实现调度循环（属 F7P1）——本 Phase 的读取原语**通过手写通道状态直接测试**，
  不经由图执行。
- 不实现条件边路由（属 F8P1）。
- 不实现 checkpoint（属 F14P1）。
- 不做「属性 / 参数化测试」层的完整枚举（属 S5 第 ③ 层，随各 Feature 增量补）。
- 不引入 `langgraph` 作为运行时依赖（本 Phase 只允许 test 侧引用）。

### 9. 红线与质量门禁

- **依赖门禁（阻断，红线）**：`langgraph` **只能**出现在 dev / test 依赖与测试代码中；
  `freegraph` 的 `Requires-Dist` 不得出现 `langgraph*` / `langchain*` / `langsmith`。
- **零出站 / 零环境变量**。
- **契约门禁第 3 项**：C4 独立回归测试常驻 CI（与 C8 一起）。
- **人工门禁**：`harness/features/<feature>/manual-verification.md`。
- **证据门禁**：差分夹具的判定结果须记录**比对的具体字段**，不得只写「一致」。

### 10. 交付物与后续

- **交付物**：稀疏读取实现、fresh 读原语、**C4 独立回归测试**、差分测试夹具
  （含 dev 依赖声明）、人工验证记录。
- **后续解锁**：**F7P1**（调度循环，用本 Phase 的读取原语实现「节点入参构造」）。
- **风险提示**：本 Phase 是**「静默破坏」防线**的第一道。测试若写成「节点入参包含
  所有 schema key」的宽松断言，就等于没有防线——断言必须是**否定式**的。
